# The End Has Come

Game Design Document (kanonik) untuk **Survival Open World + Shelter** top-down pixel art, dibuat dengan Godot 4.4.

- **Dokumen:** [GDD.md](GDD.md) — v3.2 (menggabungkan dan menggantikan v1, v2, v3.0, v3.1)
- **Dunia:** 1 kota prosedural 384×384 tile, 8 distrik (5 saat EA), 60–120 bangunan enterable
- **Loop:** siang ekspedisi → senja persiapan → malam pertahanan shelter (atau night raid berisiko)
- **Kematian:** corpse bag + respawn subuh (mode Survivor), Ironman tersedia
- **Skor:** hari bertahan
- **Rilis:** Early Access minggu 28, 1.0 minggu 44 (lihat §21)

Keputusan desain yang sudah final ada di §24.1; yang masih terbuka di §24.2. Ide yang sengaja dipensiunkan dicatat di §23 supaya tidak muncul kembali tanpa keputusan sadar.
