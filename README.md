# The End Has Come

Game Design Document (kanonik) untuk **Survival Open World + Shelter** top-down pixel art, dibuat dengan Godot 4.4.

- **Dokumen:** [GDD.md](GDD.md) — v3.3 (menggantikan v1, v2, v3.0, v3.1, v3.2)
- **Dunia:** 1 kota prosedural 384×384 tile, 8 distrik, 60–120 bangunan enterable
- **Loop:** siang ekspedisi → senja persiapan → malam pertahanan shelter, atau night raid berisiko dengan hadiah
- **Berat:** semua item punya kg; berat memperlambat gerak, sprint, dan dodge (Drop & Run tersedia)
- **Kematian:** corpse bag + respawn subuh (Survivor), Ironman tersedia
- **Skor:** hari bertahan
- **Rilis:** Early Access minggu 28, 1.0 minggu 44 dengan 8 distrik (lihat §21)

Keputusan final ada di §24.1; yang masih terbuka di §24.2. Ide yang dipensiunkan dicatat di §23.
